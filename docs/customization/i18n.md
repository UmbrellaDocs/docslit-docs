# Internationalization

DocsLit supports a lightweight locale layout without a full CMS.

## Directory convention

- Default locale content: `docs/`
- Additional locales: `docs.fr/`, `docs.ja/`, … mirroring page IDs

## Config

```json
{
  "i18n": {
    "defaultLocale": "en",
    "locales": ["en", "fr", "ja"],
    "labels": { "en": "English", "fr": "Français", "ja": "日本語" }
  },
  "sidebar.fr": [
    { "group": "Démarrage", "pages": ["getting-started/introduction"] }
  ]
}
```

Non-default locales build under `/{locale}/…` (after `basePath` if set). The nav includes a locale switcher, and pages emit `hreflang` tags when `url` is configured.
